# 🌐 Personal Portfolio Website

This is my **personal developer portfolio** built using **HTML, CSS, and JavaScript**. It showcases my projects, skills, and ways to contact me. The portfolio also includes a working contact form powered by **EmailJS** for sending messages directly without a backend server.

🔗 **Live Website:** [http://www.mohammedsadik.tech](http://www.mohammedsadik.tech)

---

## 🚀 Features

* Responsive modern portfolio design
* Project showcase section
* Skills and experience overview
* Contact form integration using EmailJS
* Smooth navigation and clean UI
* Fully responsive across devices

---

## 🛠️ Built With

* **HTML5** – Structure of the website
* **CSS3** – Styling and responsive layout
* **JavaScript (Vanilla JS)** – Interactivity and functionality
* **EmailJS** – Contact form email service

---

## 📬 Contact Form

The contact form uses **EmailJS** to send messages directly to my email without needing a backend server. This allows visitors to reach out easily from the portfolio.
